# JSNOTES releases

This repository contains the official signed Windows release files for JSNOTES. Application source code is maintained separately.

## Download

Open the [latest release](https://github.com/jemicoo/jsnotes-releases/releases/latest):

- Most Windows PCs: download the `x64` installer.
- Windows on ARM devices: download the `arm64` installer.

JSNOTES verifies in-app updates with its embedded updater public key. Release files are published here so installed copies can check for updates without access to the private source repository.
